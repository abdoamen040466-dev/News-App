# News App

A modern news application that fetches and displays the latest news articles using an external News API.  
Built with a clean and responsive user interface using modern front-end technologies.

## 🚀 Features

- Browse latest news articles
- Multiple news categories
- Responsive design for all devices
- Dynamic data fetching using API
- Search functionality
- Clean and user-friendly UI
- Fast and lightweight performance

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap
- News API
